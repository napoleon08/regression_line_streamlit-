# 통계적 회귀 분석과 기계학습 회귀 분석

통계적 회귀 분석과 기계학습 회귀 분석의 원리를
Streamlit으로 구현한 데이터 분석 프로젝트입니다.

## 주요 기능

### 1. 오차 계산
- 실제값
- 예측값
- 오차
- 오차²
- 오차 제곱의 합

### 2. 최소제곱법
- 평균 x
- 평균 y
- 기울기
- 절편
- 회귀선 계산
- 회귀선 그래프

### 3. 기계학습 회귀
- 놀이공원 대기시간 데이터
- 의사결정나무 회귀
- K-최근접 이웃 회귀

### 4. 비교
통계적 회귀와 기계학습 회귀의 차이를 비교합니다.

### 5. 퀴즈
학습한 내용을 확인할 수 있는 5개의 문제를 제공합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
